# X 貼文截圖

請使用本 Greasyfork 頁面上的安裝按鈕安裝此腳本。

在 X 原生的貼文「更多」選單中直接儲存 PNG 截圖，盡量保留目前貼文卡片、輪播位置和影片/GIF 目前影格。

> **AI 產生說明：** 本專案的程式碼完全由 AI 產生。

## 功能

- 在 X 貼文選單中加入「儲存貼文截圖」。
- 截取作者、正文、引用貼文、媒體和互動列。
- 支援時間軸和貼文詳情頁。
- 支援淺色、dim 和 lights-out 主題。
- 提供英文、簡體中文和繁體中文提示。
- 不包含遙測、統計或遠端程式碼。

## 使用

1. 在 X 開啟一則貼文。
2. 開啟貼文原生的「更多」選單。
3. 點選「儲存貼文截圖」。
4. 用戶腳本管理器會下載 PNG，頁面底部會顯示進度和結果提示。

只截取貼文卡片，不包含頁面導覽、側欄或目前開啟的選單。

## 權限

腳本使用：

- `GM_xmlhttpRequest`，僅存取 `*.twimg.com` 下的 X 媒體/字型資源，以及 `*.pscp.tv` 下的影片封面；
- `GM_getValue` / `GM_setValue` 儲存有限的診斷日誌和診斷開關；
- `GM_registerMenuCommand` 註冊診斷選單；
- `GM_setClipboard` 作為診斷匯出回退；
- `GM_download` 下載檔案。

不使用 `localStorage`、`sessionStorage` 或頁面 IndexedDB，不向第三方服務上傳資料。X 媒體 CDN 白名單之外的外部連結卡片圖片可能顯示佔位圖。

## 診斷日誌

生產建置預設不向主控台輸出日誌。診斷記錄最多 100 筆、64 KiB，保留 7 天，存放於用戶腳本管理器私有儲存。可透過管理器選單切換診斷、匯出包含錯誤資訊的 JSON 報告或清空日誌。

## 已知限制

- 白名單之外的外部連結卡片圖片可能顯示佔位圖。
- X 的 DOM 改版可能需要更新腳本。
- 瀏覽器無法讀取影片影格時會回退到封面圖。
