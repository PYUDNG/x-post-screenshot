# X 帖子截图

请使用本 Greasyfork 页面上的安装按钮安装此脚本。

在 X 原生的帖子“更多”菜单中直接保存 PNG 截图，尽量保留当前帖子卡片、轮播位置和视频/GIF 当前帧。

## 功能

- 在 X 帖子菜单中加入“保存帖子截图”。
- 截取作者、正文、引用帖、媒体和互动栏。
- 支持信息流和帖子详情页。
- 适配浅色、dim 和 lights-out 主题。
- 提供英文、简体中文和繁体中文提示。
- 不包含遥测、统计或远程代码。

## 使用

1. 在 X 打开一条帖子。
2. 打开帖子原生的“更多”菜单。
3. 点击“保存帖子截图”。
4. 用户脚本管理器会下载 PNG，页面底部会显示进度和结果提示。

只截取帖子卡片，不包含页面导航、侧栏或当前打开的菜单。

## 权限

脚本使用：

- `GM_xmlhttpRequest`，仅访问 `*.twimg.com` 下的 X 媒体/字体资源，以及 `*.pscp.tv` 下的视频封面；
- `GM_getValue` / `GM_setValue` 保存有限的诊断日志和诊断开关；
- `GM_registerMenuCommand` 注册诊断菜单；
- `GM_setClipboard` 作为诊断导出回退；
- `GM_download` 下载文件。

不使用 `localStorage`、`sessionStorage` 或页面 IndexedDB，不向第三方服务上传数据。X 媒体 CDN 白名单之外的外部链接卡片图片可能显示占位图。

## 诊断日志

生产构建默认不向控制台输出日志。诊断记录最多 100 条、64 KiB，保留 7 天，存放于用户脚本管理器私有存储。可通过管理器菜单切换诊断、导出包含错误信息的 JSON 报告或清空日志。

## 已知限制

- 白名单之外的外部链接卡片图片可能显示占位图。
- X 的 DOM 改版可能需要更新脚本。
- 浏览器无法读取视频帧时会回退到封面图。
